각 언어판은 독립적으로 사용할 수 있습니다. ZIP을 풀고 index.html을 브라우저에서 여세요. JSON 파일이 편집 원고입니다. 중국어 원판은 변경하지 않았습니다.

오프라인으로 읽으며 개인정보를 수집하지 않습니다. 외부 자료 링크는 인터넷이 필요합니다.

필터는 나이별·문제별 항목에만 적용됩니다. 아이 페이지·활동표·자료는 그대로 보입니다. 인쇄할 때 전체 내용을 펼치며 종료 후 원래 필터로 돌아갑니다.

원판 자료 확인일: 2026-10-26. 번역일: 2026-10-27. 원판의 근거와 범위를 유지한 번역이며 한국의 법률·의료 제도에 맞춰 감수한 판은 아닙니다. 링크가 있다고 독립적인 전문가 검토를 마쳤다는 뜻은 아닙니다.

Node.js에서 node tools/build.cjs 를 실행하면 다시 생성됩니다. 추가 의존성은 없습니다. data/guide.json과 data/ui.json을 편집하고 HTML·Markdown·자료 목록을 함께 갱신하세요.
