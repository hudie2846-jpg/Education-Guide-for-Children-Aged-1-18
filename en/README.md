Each package is independent. Open index.html in a browser after extracting the ZIP. The JSON files are the editable content source. The Chinese original has not been changed.

Offline reading; no personal data collected. External source links require internet access.

Filters apply only to age and problem entries. The child pages, worksheets, and sources remain available. Printing temporarily opens the whole guide and then restores your filters.

Source review date: 2026-10-26. Translation date: 2026-10-27. These translated editions preserve the original source scope and are not local legal or clinical adaptations. Source links do not mean independent expert review has taken place.

To rebuild with Node.js, run node tools/build.cjs. No additional dependencies are required. Edit data/guide.json and data/ui.json, then rebuild HTML, Markdown, and source notes together.
