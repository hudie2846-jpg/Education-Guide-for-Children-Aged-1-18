# 编辑规范

- 1—18岁逐年入口用于查找，不是能力达标表。发展、入学与青春期时间存在差异；身体和安全教育需要持续进行，不必等到某个生日。1—6岁孩子部分主要由成人转述和陪练，7岁以后按阅读能力共读或自读。
- 建议先选当前年龄，再选一个实际问题。一次尝试一种改变，观察是否适合；不要把整本书变成家庭打卡任务。说明中的练习周期属于安排示例，不是科学规定的见效期限。
- “投入”是定性实践估计；“希望改善”是目标，不是效果保证。优先级是编辑建议：紧急介入用于当前危险，优先建立用于基础条件，按需练习用于具体困难。普通条目里的升级信号同样需要立即重视。
- 证据分开呈现：每条写明专业资料支持的原则，以及本指南编写的步骤、话术与练习。未作系统综述，不给条目贴伪精确的A/B/C科学评级，也不把研究相关性说成因果。书籍用于帮助理解，不自动构成某一方法有效的证据。
- 参考来源限定为中国和美国、英国、加拿大等发达国家的官方机构、专业机构及其公开资料。本版不移植国外法律、热线、医疗流程或学校制度；具体事务按所在地确认。
- 本版由AI辅助研究与编写，尚未经儿童发展、教育和临床专家独立审校。它是一般教育参考，不是诊断、治疗或危机处置培训；有当前危险先联系当地紧急服务和合适专业人员。

## 条目要求

- 编号稳定，避免删除后复用。
- 同时写孩子的适龄练习与成人职责，幼儿练习不能变成对幼儿独立完成的要求。
- 每条包含投入、目标、具体步骤、示例、误区、复查、升级求助、依据边界。
- 专业方向引用可追溯机构来源；模板与话术明确是编辑建议。
- 不凭国籍、销量、作者头衔或脑科学比喻判定可靠性。
- 研究数字不能脱离对象和条件；本版无家庭教育效果百分比。
- 涉及医疗、安全和法律的新结论需重新查证；不直接照搬海外制度。
- 每次修改后同步生成HTML、Markdown和JSON，核对链接、年龄、证据与孩子责任边界。
- 本版为AI辅助编写，未经过独立专家审校。
