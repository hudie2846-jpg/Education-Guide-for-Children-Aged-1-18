# 編集方針

- このガイドは子どもと養育者の両方に向けたものです。子どもは表現、協力、判断、責任を少しずつ練習します。大人は環境、手本、保護、発達に合った支援を提供します。両者の責任は同じではありません。
- 1〜18歳の年齢別入口は情報を探すための区分で、発達の合格基準ではありません。発達、入学、思春期の時期には個人差があります。身体と安全の教育は特定の誕生日を待たず継続します。1〜6歳では主に大人が言葉にして一緒に練習し、7歳以降も読む力に応じて共読・自読を選びます。
- 今の年齢と、実際に困っていることを一つ選んでください。一度に一つの変更を試し、家庭に合うか観察します。全項目を達成課題にしないでください。練習期間は予定の例であり、科学的に定められた効果発現の期限ではありません。
- 「必要な負担」は実践上の目安、「目指す変化」は目標であって効果の保証ではありません。優先度は編集上の提案です。現在の危険には緊急対応、基本条件にはまず整える、個別の困りごとには必要に応じて練習を使います。通常の項目にある相談・対応の目安も見逃さないでください。
- 各項目では専門資料が支持する原則と、本ガイド独自の手順・言葉かけ・練習を区別します。系統的レビューではなく、根拠に見せかけの精密なA・B・C評価を付けたり、相関を因果としたりしません。書籍は理解を助けますが、個々の方法の有効性を自動的に証明するものではありません。
- 参考資料は中国、および米国・英国・カナダなどの先進国の公的機関・専門機関の公開資料に限定しています。外国の法律、相談電話、医療手順、学校制度をそのまま移していません。具体的な制度は居住地域で確認してください。
- 本版はAIの支援を受けて調査・執筆しており、発達・教育・臨床の専門家による独立した監修は受けていません。一般的な教育情報であり、診断、治療、危機対応の訓練ではありません。現在危険がある場合は地域の緊急サービスと適切な専門職につないでください。

改訂時は項目番号、具体的な問題、信頼できる資料を示してください。番号を維持し変更を記録します。数値には対象、結果、限界を添え、未検証の練習は提案と明示します。
