各言語版は単独で使えます。ZIPを展開してindex.htmlをブラウザーで開きます。JSONが編集用の原稿です。中国語原版は変更していません。

オフラインで読めます。個人情報は収集しません。外部資料のリンクには通信が必要です。

絞り込みは年齢別・問題別の項目に適用します。子どものページ、シート、資料は残ります。印刷時は全項目を開き、終了後に元の表示へ戻します。

原版の資料確認日：2026-10-26。翻訳日：2026-10-27。原版の根拠と範囲を保った翻訳であり、日本の法律や医療制度に合わせた監修版ではありません。リンクの掲載は独立した専門家の監修を意味しません。

Node.jsで node tools/build.cjs を実行すると再生成できます。追加の依存関係は不要です。data/guide.json と data/ui.json を編集し、HTML・Markdown・資料一覧をまとめて更新します。
