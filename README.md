# 1—18岁孩子与家长成长指南

一份面向孩子与照顾者的可查阅指南，包含18个逐年入口、42个问题条目、6页孩子共读内容、6张家庭工具表和25项专业资料来源。

## 阅读

- [完整文字版](GUIDE.md)
- [离线阅读版](index.html)：下载后在浏览器打开，可按关键词、年龄、主题、阅读视角与优先级筛选，无需安装依赖。
- [来源及延伸阅读](docs/SOURCES.md)
- [编辑规范](docs/EDITORIAL.md)

离线版不请求外部资源、不采集个人信息。外部来源链接需要联网。打印全书会临时展开全部条目并恢复双视角，打印结束后恢复原筛选。

## 内容范围

包括情绪与沟通、家长自我管理、幼儿生活、学习方法、同伴关系、数字与身体安全、独立生活和专业求助。年龄是导航，不是发展达标表。证据支持范围与原创实践明确分开；本版尚未经独立专家审校。

## 文件与更新

内容在 tools/guide-data.cjs、tools/cards.cjs、tools/extras.cjs 中维护，tools/build.cjs 生成阅读文件。data/guide.json 为同一内容的结构化导出；不要只修改导出JSON而遗漏源稿。

使用 Node.js 运行：

```
node tools/build.cjs
```

无需额外依赖。默认写入该仓库目录，也可在命令后指定输出目录。网页可直接离线打开，也适合静态托管；可下载到本地离线使用。
